# 扫描结果选择规则

在 Web 扫描结果页面点击 **Rules**：

1. 添加一个或多个需要保留的文件夹，填写运行 Web 服务的机器上的绝对路径。规则自动包含子文件夹。
2. 选择保留规则以及范围（当前页或所有筛选结果），点击 **Apply rule**。
3. 检查待删除勾选，再使用现有的移入回收站或永久删除按钮确认执行。

## 规则含义

- **Keep all files in protected folders**：保留指定文件夹里的全部文件，勾选同组其他位置的文件。没有命中保留文件夹的组跳过。
- **Keep newest/oldest creation date**：保留每组创建日期最新／最旧的文件，勾选其余文件。
- **Keep newest/oldest modification date**：保留每组修改日期最新／最旧的文件，勾选其余文件。
- 日期并列的文件全部保留。例如保留最新日期时，1 月、2 月、3 月、3 月中只勾选 1 月和 2 月。
- 所有选择方式都保护指定文件夹内的文件，包括手动选择、整组选择、反选和质量选择。添加保护时立即撤销已有的受保护文件勾选。后端删除、移动和替换链接也会检查保护。

应用规则会替换所选范围内的勾选，范围外的勾选保持原样。筛选和分页限制可勾选的文件；日期比较和保留文件判断仍使用完整重复组。应用规则不会删除任何文件。

保留文件夹与扫描结果快照一起保存，刷新页面及恢复结果时继续生效。创建日期沿用扫描记录（启用 EXIF 创建日期时遵循该设置），修改日期来自扫描记录的文件修改时间。旧结果缺少日期时，对应日期规则跳过整个组；重新扫描后可使用完整日期规则。
